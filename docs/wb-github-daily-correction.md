# WB — ежедневный CSV → GitHub Actions → официальный Seller API

НЕТ необходимости скачивать весь репозиторий или запускать `.bat`.
Вход — CSV с покупательскими ценами, собранными в Chrome.
Снимок действителен **36 часов**, как указал владелец, а не 15 минут.

## Защита информации в публичном репозитории

НЕ коммитьте полный файл `WB_prices_*.csv`: в нём есть базовые
цены и скидки продавца. В `data/wb_buyer_latest.csv` хранится
*только публично наблюдаемая витринная цена* и метаданные:
`nm_id,sku,buyer_min_rub,read_status,checked_at,source`.
Полный CSV можно прислать в чат: помощник подготовит сокращённую
версию, не содержащую внутренних цен, и загрузит её в GitHub.

GitHub Actions берёт seller base/discount **не из файла**, а
запрашивает актуальные значения через `WB_API_KEY`.
РРЦ берёт из приватного GitHub Secret `RRP_MAP_B64`.
Токен и личный прайс не публикуются в файлах и логах.

## Когда запускается

Изменение `data/wb_buyer_latest.csv` в основной ветке автоматически
запускает `.github/workflows/wb-daily-correction.yml`.
Можно также открыть GitHub → Actions → WB daily buyer snapshot
and bounded price correction → Run workflow:
- `apply=false` — расчёт, без записи;
- `apply=true` — ограниченная первая запись.

## Правила

- Действующая РРЦ и промо-акция определяются теми же функциями,
  что и Яндекс/Ozon.
- РРЦ **>1500 ₽**: идеал покупателя ×1.05, допуск ×1.02–×1.08.
  Завышение **>30%** — ручная проверка (не автоуценка).
- РРЦ **<=1500 ₽**: цена покупателя до **РРЦ ×2.00**
  допустима; выше — ручная проверка.
- Пересчёт по **индивидуальному** соотношению buyer/seller discounted
  для каждой позиции, а не по одному общему коэффициенту СПП.
- Первая партия: до **30 артикулов**, изменение базовой цены
  каждого не больше **±5%**.
- Сначала валидируется источник цены WB, время съёма **<=36 часов**,
  карта РРЦ, идентичность SKU и отсутствие WB Club/неоднозначных
  размерных цен, затем ещё раз запрашиваются цены продавца.
- Позиции без цены, без РРЦ, с «УЦ», изменёнными скидками
  или без надёжного коэффициента — без записи.
- Программа ставит задачу через `POST /api/v2/upload/task`;
  это НЕ подтверждение применения. До новой витринной проверки
  предыдущие nmID остаются в ledger.
- Результаты видны в GitHub Actions, логи не печатают
  продавцовскую базу и внутренние скидки.

**Обратите внимание:** GitHub Actions использует публичный репозиторий.
Выводит только краткие статусы. При сбое API или отсутствующем Secret
никакие изменения не отправляются. Снимок WB может оставаться
стабильным сутки, но это не гарантирует неизменности персональных
скидок и акций WB; поэтому ограничение шага и повторная сверка
цены продавца обязательны.

### Обновление от 21.10.2026

На товарах с действующей РРЦ **≤1500 ₽** верхняя допустимая цена —
**РРЦ × 2**. При равенстве коэффициенту 2 автоматической уценки нет.
РРЦ **>1500 ₽**: завышение строго **более +30%** всегда требует
согласования владельца, **включая позиции по акционному прайсу**.
Список этих товаров направляется приватно в Telegram через Secrets
`TELEGRAM_WB_BOT_TOKEN`/`TELEGRAM_WB_CHAT_ID` (если настроены).
В публичные логи RРЦ и цены продавца не выводятся.
При новой проверке предыдущие 100 отправленных nmID не корректируются
и не предлагаются повторно к согласованию до нового витринного замера.
