# Yandex Market — контроль цены с картой Яндекс Пэй

Мониторинг работает **только на чтение** и не меняет цены продавца.

## Что считается контрольной ценой

Контрольная цена — публичная зеленая цена с подписью **«Цена с картой Яндекс Пэй»**
на B2C-витрине Яндекс Маркета.

Не используются как замена:
- обычная цена продавца;
- цена акции продавца;
- промокоды;
- персональные скидки;
- любая цена без явной подписи Яндекс Пэй.

Если на странице несколько продавцов, цена принимается только когда ее можно
связать с названием нашего магазина. Если связь не подтверждена, товар получает
статус `UNVERIFIED`, а не ложный зеленый/красный результат.

## Правила

- `RED`: цена с картой Пэй ниже РРЦ.
- `YELLOW`: цена с картой Пэй от РРЦ включительно, но ниже РРЦ + 5%.
- `OK`: цена с картой Пэй не ниже РРЦ + 5%.
- товары УЦ исключаются.
- архивные товары и товары без B2C-ссылки не считаются нарушениями.

Регион по умолчанию: Москва, Yandex region id `213`.

## GitHub Secrets

Нужны:

- `YANDEX_MARKET_API_KEY`
- `RRP_MAP_B64` (тот же справочник РРЦ, который используется Ozon/WB)
- `TELEGRAM_YANDEX_BOT_TOKEN`
- `TELEGRAM_YANDEX_CHAT_ID`

Для токена Яндекс Маркета достаточно доступа к просмотру товаров и карточек
(`offers-and-cards-management:read-only`). Метод списка магазинов доступен с
этим токеном.

## Запуск

Workflow: `.github/workflows/yandex-pay-price-check.yml`

Ручной запуск: **Actions → Yandex Market Pay Price Check (Read Only) → Run workflow**.

По расписанию проверка запускается раз в 6 часов.

Диагностический artifact:
`artifacts/yandex-pay-price-audit.json`.
