# Бесплатная проверка цены WB для Москвы через Chrome

GitHub Actions (облачный IP) получил 403 на `card.wb.ru` и
`search.wb.ru`, а сайт `wildberries.ru` вернул защиту 498.
Поэтому **только с GitHub-hosted runner** достоверные цены WB в этом проекте
на данный момент не получены.

## Режим пробной проверки

Программа `wb_agent/browser_price_probe.py` открывает карточку товара
в настоящем локальном браузере и запрашивает JSON цены для
`dest=-1257786` (Москва).

- Не требует MPSTATS, сторонних платных API и API-токена WB.
- Не записывает никакие цены продавца.
- Пропускает данные, если в запросе карточки не указан нужный `dest`.
- Не подставляет исторические цены или цену со скриншота при ошибке.
- Сохраняет `artifacts/wb-browser-price-probe.json` с подробной диагностикой.
- `wallet_price_estimate_rub` — **оценка**, а не подтверждённая скидка
  для конкретного покупателя. Процент задаётся параметром
  `--wallet-pct` (для проверки сейчас 3%). Базовую цену берём
  только из действительно полученного ответа.

## Windows: самый простой запуск

1. Нужен Python 3 с сайта python.org (с установленным Python Launcher `py`).
2. Откройте папку репозитория и запустите двойным щелчком
   `scripts/wb_price_probe_windows.bat`.
3. Дождитесь установки бесплатного Chromium через Playwright.
4. При первом запуске появляется окно браузера. Если WB попросит
   подтвердить доступ / регион, сделайте это обычным способом.
5. Скрипт напечатает `public_price_rub` и ориентировочную цену с кошельком
   либо конкретную причину отказа. Результат сохраняется в
   `artifacts/wb-browser-price-probe.json`.

Команда для ручного запуска:

```powershell
py -3 -m pip install playwright
py -3 -m playwright install chromium
py -3 -m wb_agent.browser_price_probe 1308438233 --dest -1257786 --wallet-pct 3
```

## Не включать автоматическое изменение цен до проверки

Нужно хотя бы на 2–3 артикулах сравнить `public_price_rub`
с ценой WB для Москвы (не Санкт-Петербурга) и проверить наличие,
продавца и фактическую применимость скидки WB Кошелька.

Результат этого модуля **не подключён к автоматической записи цен**.
После успешной сверки его можно использовать в локальном планировщике
Windows или на собственном runner, где браузер имеет доступ к WB.
Облачная GitHub Actions-джоба от этого работоспособной не станет.
