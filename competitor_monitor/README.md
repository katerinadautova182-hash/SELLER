# Мониторинг РРЦ JRL — 8 интернет-магазинов

Ежедневный контроль публичных розничных цен JRL в GitHub Actions с отдельным
сообщением Telegram для **каждого из восьми магазинов**.

## Что увидит менеджер

Первая строка: **домен сайта — наименование продавца (ИП или ООО)**.
Далее: подтверждённые позиции JRL **ниже РРЦ**. По каждой позиции обязательно:
название товара, артикул, цена на сайте, РРЦ, отклонение в рублях и ссылка.

Ни технические сообщения о неподтверждённых соответствиях, ни обозначение
«Тестовая проверка» в уведомления не попадают. Если цены проверить не удалось,
сообщение прямо говорит об отсутствии подтверждённых цен, а не о соблюдении РРЦ.
Результат для каждого сайта отправляется отдельно.

## Источник РРЦ (не секрет!)

`competitor_monitor/jrl_rrp.csv` — прайс из Google-таблицы
**«База РРЦ — Mark Shmidt & JRL»**, вкладка **«База РРЦ»**, сверка 23.10.2026.
В нём **219 уникальных артикулов JRL** и собственно их РРЦ.
Секрет `RRP_MAP_B64` **не используется**, так же как и закупочные цены.

В `competitor_monitor/rrp_reference.json` сохранены нормализованные артикулы
и контрольная сумма всех 219 цен. Перед проверкой сайтов система сверяет CSV
с этим контрольным слепком и при несовпадении прекращает запуск.

Если официальная таблица РРЦ обновилась, нужно одновременно изменить CSV и
контрольную сумму; без этого проверки остановятся, чтобы не рассылать неверные
результаты. Пока изменения Google-таблицы **не синхронизируются автоматически**
с GitHub. Прямая выгрузка требует отдельной настройки доступа.

ссылку на источник и статус подтверждения. Новые сайты добавляются туда.

## GitHub Actions

`.github/workflows/jrl-competitor-monitor.yml` запускает монитор по расписанию
в 09:00 МСК и вручную из раздела **Actions → JRL competitor price monitoring**.

Потребуются только настройки Telegram:
`TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.

После каждого запуска в артефактах сохраняются:
- `jrl_monitor.csv` — цены, ссылки, коды, статусы и технические наблюдения
- `jrl_monitor.json` — полный протокол восьми сайтов
- отдельные `*.txt` — полный список сопоставленных позиций каждого сайта

Команды для локальной проверки с Python 3.12:

```bash
pip install requests beautifulsoup4 pytest
python -m pytest -q tests/test_competitor_monitor.py
python -m competitor_monitor.monitor --no-telegram --max-products 8
```

Монитор работает только на чтение. Динамическая вёрстка, CAPTCHA, блокировки
и отсутствие нужных товаров могут приводить к неполному охвату. Не считаем
отсутствие нарушений доказанным, если сайт не удалось проверить.
