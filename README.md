# Экспорт данных Ozon Seller API

Скрипт выгружает по кабинету Ozon Seller полный набор данных о товарах:
список и остатки, карточки (характеристики/изображения/описание), отзывы,
вопросы-ответы, статистику продаж за 12 месяцев и остатки FBO по складам.
Результат сохраняется в `output/*.csv` (`;`, UTF-8-sig) и `output/*.xlsx`.
Сырые JSON-ответы API складываются в `raw/` — на случай сбоя данные не
нужно перезапрашивать заново, финальные таблицы можно перестроить из них.

## Установка

```bash
pip install -r requirements.txt
```

## Ключи доступа

Ключи **никогда** не хранятся в коде и не должны попадать в git. Задайте их
через переменные окружения:

```bash
export OZON_CLIENT_ID="..."
export OZON_API_KEY="..."
```

либо скопируйте `.env.example` в `.env` и впишите значения (`.env` в `.gitignore`).

## Запуск

```bash
python3 main.py
```

Скрипт печатает прогресс по каждому шагу. Между запросами выдерживается пауза
(`ozon_export/config.py: REQUEST_DELAY`, по умолчанию 0.5 сек), при HTTP 429/5xx
запрос повторяется с увеличивающейся задержкой (до 5 попыток).

## Что выгружается и какими методами

| # | Файл | Метод(ы) Ozon Seller API |
|---|------|---------------------------|
| 1 | `1_tovary` | `POST /v3/product/list`, `POST /v3/product/info/list` |
| 2 | `2_kartochki_tovarov` | `POST /v4/product/info/attributes`, `POST /v1/product/info/description` |
| 3 | `3_harakteristiki` | `POST /v4/product/info/attributes` + справочник названий `POST /v1/description-category/attribute` |
| 4 | `4_izobrazheniya` | `POST /v4/product/info/attributes` (поля images/images360/pdf_list) |
| 5 | `5_otzyvy` | `POST /v1/review/list` |
| 6 | `6_voprosy` | `POST /v1/question/list` |
| 7 | `7_otvety` | `POST /v1/question/answer/list` |
| 8 | `8_prodazhi_po_mesyatsam` | `POST /v1/analytics/data` (помесячно, dimension=sku) |
| 9 | `9_prodazhi_itogo_12mes` | агрегат по данным `analytics/data` за 12 месяцев |
| 10 | `10_ostatki_fbo_po_skladam` | `POST /v1/analytics/stock_on_warehouses` |

## Важные оговорки

- **Документация не была доступна напрямую в момент разработки**: и
  `docs.ozon.ru`, и `dev.ozon.ru` в этой среде отвечали `HTTP 403`
  (похоже на защиту от автоматических обращений). Список методов и их схемы
  собраны по актуальным на 2025–2026 год данным (включая переход `v2 -> v3`
  для `product/list`/`product/info` в феврале 2025 и появление
  `v4/product/info/attributes`), перепроверенным через веб-поиск, но **не
  подтверждены напрямую по официальной документации**. Если какой-то метод
  в вашем кабинете называется иначе или ответ имеет другую структуру —
  скрипт не упадёт молча: он логирует HTTP-статус и тело ответа в `raw/`,
  печатает предупреждение в консоль и продолжает выполнение остальных шагов.
  Проверьте вывод консоли на строки `!!` после запуска.
- **Отзывы (`review/list`) и вопросы-ответы (`question/*`)** по данным Ozon
  доступны только с подпиской **Premium Plus** (отзывы) и являются beta-методами
  (вопросы-ответы). Если у аккаунта нет нужного тарифа/доступа, эти шаги
  вернут `403`/`404` — скрипт создаст пустые файлы с заголовками и явно
  сообщит об этом в консоли, не прерывая остальную выгрузку.
- **`analytics/data`** у Ozon исторически ограничивался по объёму/срокам в
  зависимости от тарифа и оборота продавца. Если 12-месячный период целиком
  недоступен, соответствующие месяцы в `8_prodazhi_po_mesyatsam` останутся
  пустыми, а не вызовут падение скрипта.
- Каждый модуль (`ozon_export/*.py`) обёрнут так, чтобы ошибка одного шага
  (например, недоступность отзывов) не прерывала остальные — в `main.py`
  все шаги, кроме первого (список товаров), запускаются с перехватом ошибок.
- `raw/` и `output/` добавлены в `.gitignore` — в git репозитория попадает
  только код, реальные данные магазина и ключи никогда не коммитятся.

## Структура проекта

```
ozon_export/
  config.py       — переменные окружения, базовые настройки
  client.py        — HTTP-клиент: заголовки Client-Id/Api-Key, троттлинг, retry, сохранение raw JSON
  utils.py          — защитное извлечение полей из ответов (на случай расхождений схемы)
  writer.py         — запись CSV (; , utf-8-sig) и XLSX с русскими заголовками
  products.py       — товары и остатки
  cards.py          — характеристики/изображения/описание
  reviews.py        — отзывы
  questions.py       — вопросы и ответы
  analytics.py       — статистика продаж за 12 месяцев
  fbo_stocks.py       — остатки FBO по складам
main.py             — точка входа, оркестрация шагов
```
