# SELLER — бесплатная проверка цены покупателя WB

Использует **обычный Chrome**, без Selenium, Playwright или автоматического
логина; при необходимости пользователь входит в WB на официальном сайте
и выбирает город **Москва**. Расширение не читает cookies, пароли или API-ключи.

## Установка

1. Скачайте репозиторий SELLER (`Code → Download ZIP`) и распакуйте.
2. В обычном Chrome откройте `chrome://extensions`.
3. Включите «Режим разработчика», выберите «Загрузить распакованное расширение».
4. Укажите папку `chrome_extension/wb_price`.
5. Закрепите значок расширения (значок пазла в Chrome).
6. Проверьте артикул `1308438233` кнопкой **«Проверить API для Москвы»**.
7. Если API вернул ошибку, откройте карточку в обычном Chrome, выберите
   Москву на сайте, при необходимости войдите в аккаунт WB.
8. Вернитесь к значку расширения на вкладке карточки, подтвердите город и
   нажмите **«Считать обе цены с открытой карточки»**.
9. Нажмите «Скачать CSV для SELLER».

## Два независимых источника

- **API:** запрос к `card.wb.ru/cards/v4/detail` с `dest=-1257786`. Цена
  со скидкой WB считывается из JSON при подтверждённом наличии.
  Кошелёк — **расчётная цена**, процент задаётся вручную (сейчас 3%);
  она не объявляется фактической ценой покупателя.
- **Страница:** расширение считывает элементы, отображающие обычную
  цену и цену с кошельком непосредственно в открытой карточке WB.
  Регион Москва подтверждается пользователем вручную. Никаких других
  элементов страницы, cookies и паролей не собирается.
  Если WB поменяет классы HTML, скрипт выдаст ошибку, а не подставит цифры.

## Безопасность и ограничения

Нет API-токенов продавца, записи цен, загрузки в сторонние сервисы,
облачного планировщика или массовых запросов. Данные сохраняются
только в локальном хранилище расширения (до 200 артикулов)
и могут экспортироваться в CSV. На GitHub Actions с облачным IP
цена из WB по-прежнему может быть недоступна (HTTP 403/498).

**Пока это не автоматический репрайсер.** Сначала следует подтвердить
на 2–3 товарах с выбранным регионом соответствие цен витрине.
