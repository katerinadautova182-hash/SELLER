# SELLER WB Auto — автоматический сбор цены покупателя

## Схема

1. После однократного ввода токена только категории **Цены и скидки** расширение
   читает весь каталог продавца через официальный метод
   `GET https://discounts-prices-api.wildberries.ru/api/v2/list/goods/filter?limit=1000&offset=...`.
   Токен применяется только к этому запросу, не сохраняется.
2. В обычном Chrome открывается одна вкладка Wildberries.
   Программа автоматически переходит по всем `nmID` из ответа Seller API.
   Регион не выбирается и не проверяется: используются обычные условия текущего браузера.
3. Контент-скрипт читает **видимую цену со скидкой WB**, а при наличии
   вторую цену **с WB Кошельком**, непосредственно из страницы.
   Цена продавца в отчёте — отдельно, из Seller API, не заменяет цену покупателя.
4. Прогресс, ошибки и успешно считанные цены сохраняются локально в Chrome.
   Доступна выгрузка CSV (разделитель ;, UTF-8 BOM).
5. Автоматической записи цен продавца **НЕТ**.

## Установка

Откройте `chrome://extensions`, включите режим разработчика и загрузите
`chrome_extension/wb_auto/`. Старое расширение «SELLER — цена Wildberries»
лучше выключить. Значок нового расширения появится в Chrome.

Нужно лишь ввести токен WB с разрешением «Цены и скидки» и нажать
«Начать автоматический сбор». Значение «Проверить товаров = 0» означает весь каталог.

Расширение само берёт артикулы, само открывает карточки по одной, ждёт
загрузки цены, сохраняет результаты и продолжает цикл. Для сверки
можно временно ограничить проверку до 3 товаров, но это необязательно.

## Защита

- Нет сторонних сервисов, платного API или Playwright.
- Нет чтения паролей, cookies, данных личного кабинета.
- Нет вызова POST `/api/v2/upload/task` и других методов изменения цен.
- Токен не записывается ни в `chrome.storage`, ни в файл.
- Программа останавливается после 3 подряд подтверждённых блокировок.
- При отсутствии цены в DOM сохраняет ошибку, не придумывает число.
- Сбор идёт в обычном Chrome в одной вкладке, с паузами между товарами.
- Если сайт WB меняет верстку, парсер может не находить цену. Реальная
  успешность получения цен ещё требует проверки на рабочем браузере.

## Ограничения

Это **первая версия автоматического браузерного сборщика**, а не проверенное
решение для круглосуточной работы. Наличие авторизации WB в браузере не даёт
гарантии доступа к ценам; возможны блокировки / ограничения со стороны WB.

CSV можно загрузить в основной модуль контроля РРЦ после проверки точности
на 2–3 известных карточках. Автоматическое изменение цен пока выключено.
